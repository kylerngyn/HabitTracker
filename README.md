# Habit Tracker

A web app for tracking daily habits and streaks, built with Flask and SQLite

<!-- Instructions for anyone to run the project -->

## Setup

1. Create a virtual environment: `python3 -m venv venv`
2. Activate it: `source venv/venv/activate` (Windows: `venv\Scripts\activate`)
3. Install dependencies: `pip install -r requirements.txt`
4. Run the app: `python3 app.py`
5. Open http://127.0.0.1:5000
